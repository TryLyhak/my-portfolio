# Try Lyhak — Angular Portfolio

A responsive, modern-dark personal portfolio built with standalone Angular components and plain CSS.

## Included
- Responsive navigation with mobile menu
- Hero section and developer-style code panel
- About, skills, projects, journey and contact sections
- Project and skills data kept in the Angular component
- Responsive layouts and reduced-motion support
- No extra UI library required

## Requirements
- Node.js version supported by Angular 22
- npm

Check the current Angular compatibility table before installing: https://angular.dev/reference/versions

## Run locally

```bash
npm install
npm start
```

Open the local URL printed by Angular CLI (usually http://localhost:4200).

## Production build

```bash
npm run build
```
